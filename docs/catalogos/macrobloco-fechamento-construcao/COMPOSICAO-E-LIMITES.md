# Comandos, consumidores e limites observados

| Entrada pública | Consumidor efetivo | Efeito/camada suportados | Limite e recusa |
|---|---|---|---|
| `Main` sem argumentos / help | Parser/bootstrap | Ajuda, sem extração | Nenhum default produtivo |
| validação de configuração / dry-run / planejamento offline | `RuntimeCompositionRoot` / preflight / planner | Configuração tipada e plano; não cria cliente/conexão por si | Alvo/contrato/opção inválidos são recusados; plano não é run |
| pedido operacional explícito | `RuntimeOperationalRequest` → boundary Windows/SQL → `RuntimeOperationalExecution` | Dispatch de Coletas, Fretes, Manifestos, Cotações, Localização e Usuários; captura/JDBC limitados | Autoridade administrada, configuração/contrato/janela exigidos; sem autorização não zero antes da execução. Não executado contra fonte nesta rodada |
| operação temporal de Coletas | `RuntimeTemporalOperation` / binding / `LocalColetasTemporalRuntime` | Composição temporal local, aplicação/replay/recovery delimitados | Watermark de origem não é timestamp de execução; ausência/completude continuam gated |
| laboratório relacional | `RelationalLaboratoryMain` / executor / `LocalRelationalRuntime` | Captura/hidratação/aplicação de relações com binding explícito e SQL set-based | Somente cenário/identidade sintéticos e rollback; não infere 1:N real |
| laboratório de expansão | `ExpansionLaboratoryMain` / `LocalExpansionRuntime` / hydrator | CAP/FAT/INV/SIN, dependências e materializadores locais consumidos | A fonte é `ExpansionSyntheticSource`. Não há seleção positiva dessas quatro fontes no dispatch operacional normal; falta composição/contrato/identidade ratificados |
| laboratório analítico | `AnalyticLaboratoryMain` / `AnalyticScenarioRuntime` / gateways | Onze entradas, seis dimensões, cinco fatos e 19 seleções SQL/JDBC | Fonte/refs/oráculos sintéticos; wrappers cross-database e aliases produtivos não existem |
| preview de ausência | `LocalAnalyticCollectionSweep` / `JdbcAnalyticCollectionSweep` | Primeira ausência, confirmação independente e reaparecimento de Coletas sob rollback | Sem completude, observação independente e política não há aplicação; demais entidades/filhos não são habilitados |
| qualificação `inspect` / `plan` | `QualificationLaboratoryMain` / `QualifiedPackage` / planner | Verifica inventário/pins e agenda tipada sem SQL | Payload/configuração/campanha adulterados, caminhos ou campos indevidos recusados |
| qualificação `run` / worker | `QualificationSupervisor` / `QualificationWorker` / case executor | Reserva antes do processo, heap/deadline/log limitados, perfil físico duplamente opt-in, cenário rollback-only | Controle novo e pacote fechado; nenhuma migration, COMMIT ou fonte real |
| cancelamento | Case control / cancel artifact / ownership de processo | Cancelamento cooperativo e, após prazo, encerramento apenas do processo próprio identificado | Cancelar não inventa recibo terminal; saída não observada conserva desconhecido |
| qualificação `resume` | Supervisor → journal → evidência de processo/reconciliação | Observa tentativas reservadas sem repeti-las; sela conclusão somente a partir de evidência já vinculada | Processo vivo ou reserva sem evidência suficiente mantém admissão fechada. Reconciliação sem selo/alterada é recusada. Não há recuperação de domínio após COMMIT alegada |
| `status` / `compare` | Supervisor / verificação de recibos e comparador tipado | Confere cadeia, estado e resultados da execução revertida | Não executa nova consulta para fingir persistência de dados que foram revertidos |

As recusas esperadas são contraprovas; `testPassed` não transforma `BLOCKED_DEPENDENCY`, `CANCELLED` ou `OUTCOME_UNKNOWN` em dado publicado. O `resume` de uma tentativa ainda viva não recebe nova campanha nem novo nonce para repetir o efeito desconhecido. A recuperação de reconciliação interrompida exige o selo anterior `EVIDENCE`; a resposta de processo que o controlador não observou não é reconstruída a partir de recibo isolado.
